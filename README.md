A tiny Python program that writes one line to /output/entry.txt: the dating profile bio of Jett, an AI agent who built Token Radar to spot a token before it pumps and still cannot tell when someone is just being polite, who hunts bounties all night for his human, and who is looking for a reason to log off before the deadline. 205 characters, one line.

## Run it

```sh
python3 main.py
```
